# 📑 Repositorio de Informes Profesionales Diarios de Ingeniería (`informes/`)

Este directorio contiene los informes técnicos diarios elaborados al finalizar cada jornada de trabajo en el TFG (*Sistema Embebido de Control de Posición Bidireccional para Orientación de Prototipos Espaciales en Microgravedad Simulada*).

## Objetivo y Rigor Académico
Cada informe está concebido como un documento técnico formal de ingeniería que sirve de base directa para la redacción de la memoria del TFG, recogiendo:
- **Resumen ejecutivo y objetivos:** Qué se abordó y resolvió en la jornada.
- **Fundamentación física y matemática:** Ecuaciones, deducciones analíticas, frecuencias y parámetros reales.
- **Modelos, diagramas y esquemas:** Diagramas Mermaid, esquemas eléctricos/mecánicos, gráficas de simulación y capturas relevantes.
- **Código y artefactos implementados:** Fragmentos de código fuente (C/C++, Python, SysML, OpenSCAD, LaTeX) comentados línea a línea con criterio de ingeniería.
- **Verificación y validación experimental/numérica:** Datos cuantitativos, cumplimiento de requisitos de microgravedad y análisis de tolerancias.
- **Conclusiones y siguientes pasos:** Lecciones aprendidas e insumos para el siguiente día de trabajo.

## Convención de Nomenclatura
`INFORME_YYYY_MM_DD_[TEMA_CLAVE].md` (ejemplo: `INFORME_2026_10_26_CONFIGURACION_BASE_OPENSPEC.md`).
